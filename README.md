# Shehar Flow

City traffic intelligence platform for Pakistani cities.

## Problems it solves

1. **Mixed Traffic & Motorcycle Conflict** — high-risk mixing zones
2. **Informal Parking & Encroachment** — capacity loss from illegal parking
3. **Delivery Bike Impact** — congestion from delivery bike clusters

## Features

- Secure login with role-based access (viewer / operator / admin)
- Live map of Karachi with severity-colored markers
- Hotspot tracking and alerts
- Analytics charts (by type and severity)
- Admin can create and deactivate hotspots
- Contact form for city officials

## Tech Stack

- **Frontend:** React (Vite), Tailwind CSS, Leaflet, Recharts
- **Backend:** Node.js, Express, MongoDB, JWT
